# D·decode 形状 GEMM-AR 微基准方案(paper2 机制验证)

日期:2026-10-11 · 脚本:`phaseD/run_d_microbench_scnet.sh`(自包含,内嵌 `d_bench_core.py`)
平台:单机 8×BW1000 vcjob(节点内 P2P/IPC,无需 shca)· torch 2.7.1 + RCCL

## 1. 要回答的三个问题

| # | 问题 | 依据 |
|---|---|---|
| D1 | E1 的 k*=1(chunk 化从第 2 块起净负)能否被物理实验复现? | E1 是 trace 仿真(离线),审稿人会要实测 |
| D2 | M4 分域规则的分界 α 是多少?(GEMM_chunk_time vs δ 的交点) | paper1 chunk 化收益在大 M prefill;decode 小 M 待测 |
| D3 | M3(FILL)与 M2/M3 混合(PARTIAL)各自能换回多少等待? | A(可预测 0.933@5.4ms)+ B1(wait 全裸露)+ B2(host 侧成因) |

## 2. 负载与形状(对齐 ④'/③ 实测)

- 链单元 = Llama3-70B TP8 的 MLP down_proj:`(M,3584)×(3584,8192) → AR(M×8192)`
- AR 消息 = M×8192×2B(M=16 → 256KB,与 ④' 实测 wire 23µs 同量级)
- M ∈ {8,16,32,64,128,256};GEMM_ONLY / AR_ONLY 先单独标定(α 的两个输入)

## 3. 机制与网格

| mech | 内容 | 验证对象 |
|---|---|---|
| BASE | k=1 整块 GEMM→AR | 基线(含全部等待) |
| CHUNK | k∈{2,4,8} 行分块,逐块 AR | M4/D1(paper1 机制在小 M) |
| FILL | AR 上 comm 流 + n∈{1,2,4} 个 filler GEMM(256×3584×8192)上计算流 | M3(等待窗注入) |
| PARTIAL | 非 straggler 等待期先做排除 straggler 的 7-rank AR;straggler 到达后 bcast partial、相加、再 bcast final | M2/M3 混合(预测驱动预规约,把 min(δ,t_AR7) 死等换成 wire) |

- straggler 注入:**host 侧 spin 延迟**(B2 证实真实成因是 host 断粮,不是 kernel 慢);
  模式按 A 实测结构:粘性 RUNLEN=80 + SUBSET={1,3,5,7} 轮换;
  δ ∈ {0,250,500,1000}µs。
- 每格:WARM=8 + ITERS=128,迭代间 barrier 对齐;计时 = CUDA event,聚合取
  **rank-max**(与 phaseB 口径一致);正确性:每 M 对 BASE/CHUNKmax/FILL/PARTIAL
  各验一次(fp32 世界 AR 为参考,atol/rtol 2e-2,paper1 口径)。
- 注入自检:BASE(δ=500)−BASE(δ=0) ≈ 500µs 打印校验。

## 4. 判据(证实/证伪)

- **D1 证实**:CHUNK(k>1) 在 δ≥250 下 p50 > BASE(k=1),且差值随 k 单调变差;
  D1 证伪(=chunk 在 decode 也赢)→ M4 规则改写,回到 paper1 叙事,同样是结果。
- **D2 定标**:对每个 M,取 CHUNK 首次劣化点,结合 t_gemm(M) 拟合
  `chunk 有益 ⇔ t_gemm/k > α·δ` 的 α(预期 α≈1 附近,交点 M≈128-256)。
- **D3 收益曲线**:
  - FILL 增益 = (BASE − FILL_n)/BASE,对 δ 与 n 的曲线;瓶颈=filler 与 AR 抢 SM
    (净增益为正即 M3 成立,负则说明并流干扰主导,记录干扰率);
  - PARTIAL 增益同式;预期小 M(t_AR7≪δ)增益≈t_AR7/δ 上限,大 M 接近
    FILL;PARTIAL 是"wait 换 wire"的直接量化(vs StragglAR 的算法级单 straggler,
    我们是运行时多 straggler 轮换)。
- 风险与注意:RCCL 双流并发未在本机预验证(容器无卡)→ **SMOKE=1 先行**;
  PARTIAL 协议(两条 bcast)若 verify FAIL 则弃该 mech 保留其余格。

## 5. 与 paper2 的映射

- D1/D2 → M4 统一分域规则(第一篇 prefill chunking + 第二篇 decode k*=1 一条曲线);
- D3-FILL → M3 等待窗注入的上限;
- D3-PARTIAL → M2 的可运行雏形(预测→预规约),与 A 的命中率数据互证;
- 后续 v2:同一网格接 DUSHMEM 单边路径(phaseB d 族)→ selector 探针三层分发
  实装;再在 triton-dist-dcu kernel 上重跑同网格(两级证据:harness→基座)。
