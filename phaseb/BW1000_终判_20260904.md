## 3. formal 双批结构发现（np4=645 / np8=645，各 21 边界格）

以下用控制表口径（正=所列路径**快**；与终判表 (t_路径−t_基准)/t_基准 相反，引用时注意换算）。

### 3.1 ★r1 不再统治（对 selector 叙事的最大冲击）
- K500 np4：always-r1 9/9 最优（regret 0）。
- **bw1000 np4：r0 赢 6/11、r1 赢 4/11、rs 赢 1/11**（4096/q2 近平 0.95%）；r1/r0 最差 −79.9%（2048/q8）。
- **bw1000 np8：r0 赢 7/11、r1 赢 4/11**（2048/16、4096/4、4096/8、4096/16）。
- → "慢基座可短路 selector"（【15】§4 对 K500 的表述）**不外推**：bw1000 同为慢基座，零知识默认 p95 最好也要 9~22%。
  选择问题在第三基座显形，且方向又翻（A800 最优默认 d0 / K500 r1 / bw1000 r0 但不优）。

### 3.2 ★np 缩放不对称（d 族边界的机制）
np4→np8 同格倍率（C0）：
- comm ~2.0×；fcollect 地板 3.35→7.09ms（2.12×，随 np 线性）；
- d0 大格 ~2.1×；
- d1：512/q8 **5.16×**（3.23→16.67ms，超线性崩塌）/ 2048/q8 1.40× / 4096/q8 **1.55×（次线性）**。
- d1 的税 ∝ q·(np−1)（每片推 np−1 个对端），d0 的收集 ∝ np → rank 数增长把 d1/d0 交叉点在 N 轴上**先推右（小格）后推左（大格）**，
  (4096,q8) 正好落在线上：np4 d1 慢 14% → np8 d1 快 16%。
- GEMM_ONLY 同 (N,q) 下 np4→np8 ~2×（每 rank FLOPs 未变但时间翻倍；疑似 8 卡满载时钟/主机侧争用，无时钟遥测佐证，只记录不解释；不影响批内配对）。

### 3.3 传感器论点第三基座复现
- isolated 榜首 **永远** 是 COMM_ONLY，gap 70–90%；e2e 榜首 gap 仅 2–38%，且 isolated 排序对 e2e 排序无指示。
- cross-substrate（isolated vs e2e 家族）反转 0/21——因为 e2e 赢家清一色 RCCL 族；**r1/d1 列全正（r1 比 d1 快 19–87%）**：d 族在 bw1000 全域无竞争力（win 格 d1 赢 d0 但仍输 r0/r1）。
- RCCL 内部 C0/C2 **config 反转 4 格**（np4: 4096/{2,4}；np8: 2048/2, 4096/8）：C2 isolated 慢 19–23%却在 e2e 反超——"isolated 传感器误导 e2e 选择"在 config 轴第三基座复现。
