# P16 预注册：边界定律外推三格裁决（2026-09-03 发射前写死）

> **一句话**：用 3 个 clean 表外格（模型外推、从未有 f17aae1d d 族 clean 值）裁决
> 边界定律闭式 `P ≈ −44.3 + 9.22·q + (0.032−0.0154·q)·cols`（pt，R²=0.907，符号
> 11/11）的外推有效性。**主张是符号/边界律，不是幅度律**（LOO-RMSE 15pt）。
> **纪律**：与 P15 同日不同结果根；共用 f17aae1d 二进制（sha 守卫同款）；
> 跑批期间不可 make；rep 外层交错；失败 case 保留。
> **联动**：N8192/q16 与 P17-2 A800 matched 同格——两侧各自预注册、各自基座实测，
> 双基座对表是论文跨基座节的定版素材。

## 0. 封存依据

- 拟合输入 = 11 个 clean 格（N∈{512,2048,4096} 全 q + 两个 q16 fill），**无 N8192、
  无 q32**——三格均为真外推。
- 控制量锚点：C(q)=3938+38.1q µs；FC=11566µs 全格常数；G=a+b·N+c·q。
- 符号约定（立法不可改）：P=(T_d1−T_d0)/T_d0，正=d1 更慢。
- 预测值（闭式代入）：
  - N8192/q8（cols=1024）：−44.3+73.8−93.4 = **−63.9pt**
  - N8192/q16（cols=512）：−44.3+147.5−109.7 = **−6.5pt**
  - N4096/q32（cols=128）：−44.3+295.0−59.0 = **+191.7pt**

## 1. 矩阵

3 格 × {d0, d1} × 5 rep = 30 case。**格序固定为 (4096,32) → (8192,8) → (8192,16)**：
最超包络的 q32 排第一，其首个 case 即天然冒烟（分配/协议若崩立即暴露，不烧后面机时）。

| 格 | 角色 | 预测 | 判据 |
| --- | --- | ---: | --- |
| N8192/q8 | 深赢区外推 | −64pt | **E1**: P < −30 → HIT |
| **N8192/q16** | **主裁决格**（模型 −6.5 贴边界） | −6.5pt | **E2**: −20 < P < +10 → HIT（带内=符号带不确定但幅度验证）；P < −20 → 符号 HIT + 幅度低估（边界右移，进模型修订）；P > +10 → MISS（闭式在该区失效） |
| N4096/q32 | q 轴爆炸延续 | +192pt | **E3**: 只判单调——P > +80 且 T_d1 > T_d0 → HIT（爆炸延续到 q32）；P < +80 → "饱和"（UNDETERMINED-饱和，非 MISS，同样可写：q 爆炸存在上界） |

- **E4（幅度层）**：|P_meas − P_fit| 与 11 格 LOO-RMSE(15pt) 同量级 → 外推有效；
  N8192 两格 >30pt 系统性偏离 → 模型需 N 交互项（符号律不因此推翻，只降幅度主张）。
- **判定纪律**：符号优先；q32 判级降为单调延续（超 q≤16 包络）；p50 主口径 p95 辅；
  E2 裁决格无论落带哪一侧都定版素材（三分支全部预注册无输家）。
