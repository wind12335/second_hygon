## 结论(论文可直接引用)

1. 在实测到达分布下,**chunk 化细粒度重叠从第 2 块起期望净收益为负**(所有地板假设下 k*=1),
   而不是"收益打折"——这把"wait 侧是 fusion 谱系前置条件"从定性论断变成定量结论;
2. 绑定项不是协议地板,是**粘性 straggler**:每个 mini-barrier 重新付 ~δ(p_stay=0.977,
   mean run 42.6 个 AR),k 块 ≈ k×δ;
3. chunk 化打平的唯一路径 = "straggler 严格一次性"+"地板 ≤20µs"同时成立——前者被
   run 长(max 364)直接否定;
4. 反过来说:先消 wait(我们的路线),chunk 化的收益才可能兑现 → P0(eager wait 调度)
   是 P2(chunk RS+AG)的前置,排期自洽;
5. k=1 行即 wire-only 上限:完美藏线也只能省 92µs/AR → 1.14×,与 §4.4 梯子一致。

## 假设与局限

- 每块按完整集合语义(Tree-LL 到齐才走)建模;收益侧取完美藏线上界 min(W,C),
  对 chunk 化方案是慷慨假设,结论只会更差;
- 等待不能被同层计算遮住(数据没到无法算),可被"不依赖对端的独立工作"消解——
  那正是本论文的调度路线,不在本模拟的收益侧;
- C_slot=110.7µs 用窗口全部计算 ÷ AR 数(含注意力/杂项),偏高即收益上界偏松;
- 单次运行内的 41,538 个样本;run-to-run 稳健性待 ③×2 重复实验补。
