# 第二篇论文骨架与创新点主张（v1）

日期：2026-09-02。基于：三路文献调研（`20260902_文献调研2025-2026/`）+ Phase 1-3 / Phase A / Phase B formal 部分数据（`results/k500sm_ai_gfx928_4gpu/`）。

## 0. 一句话主张（thesis）

> 在 GPU 集群上为"集合通信 + 计算"选重叠策略时，业界通行的 isolated 带宽排名**既不充分也不可靠**：端到端赢家由**完成语义（依赖释放结构）× 分片粒度 × 通信资源配置**三者的交互决定——我们首次把这三条轴放进同一统一基准，证明两类排序反转（资源轴、结构轴）都真实存在且统计显著，给出"语义强度 × 重叠收益"的代价测量学，并在 NVIDIA（NCCL/NVSHMEM）与海光 DCU（RCCL/DUSHMEM）双基座上给出释放感知的选择器原型。

## 2. 贡献列表（C1-C4）

**C1 反转图谱 + 平衡律（资源轴 + 结构轴两类反转，全格显著；反转模式本身可预测）**
- 资源轴（10 格全矩阵含 q16）：C2(Ring/Simple/ch8) isolated 全 10 格恒快 +0.73~3.15%（SIG，5/5 reps），但 e2e 出现**有界共振带**：N512 +5.2→+1.7→+0.2（未穿零）；N2048 +5.7→+1.7→**−5.5（反转，SIG）**；N4096 +4.1→+0.1→**+1.8（回弹）**；**N2048/q16 −5.4（反转持续但饱和）**。Phase 2/3 的 STRONG_REVERSAL 已在 Phase B 统一口径下复现并加固。
- **★平衡律（预注册 P2 MISS 后提炼，q16 加固）**：反转需 (q≥8 ∧ ratio≈1 ∧ gap 薄) 三条件同时成立；带内全列（N2048，ratio≈1.2 恒定）delta 随 q 走 **+5.65→+1.69→−5.49→−5.37**——q 阈值 8、16 处饱和。机理三段论：通信主导传导带宽优势 / **平衡点双资源饱和、通道竞争偷 GEMM 关键路径** / 计算主导被 GEMM 阴影淹没。iso_gap 与 N 无关但随 q 单调变薄（gap=q 传感器、ratio=N 传感器，不可互替）。**预注册 P2/P3/P4 三次单调外推全 MISS（回弹/饱和/见顶）**——反转是 (q,ratio,gap) 空间的有界带，单坐标单调模型必错。
- 结构轴：DUSHMEM 家族内 d1（put-signal 逐片释放）vs d0（fcollect 整块）赢家随 q 翻转，**q8 全列反转**：N512 −45.4 / N2048 −41.1 / N4096 −19.4（d0 全赢，SIG 5/5；q2/q4 均 +21~30% d1 赢）。
- 含义：无论调资源（Lagom 的轴）还是换机制（FlashOverlap 的做法），孤立依据都选不出端到端赢家；且失效模式本身可从 isolated 可测量（q, ratio, gap）预测——选择器必要性的最硬论据。

**C2 语义代价测量学（"释放语义强度"首次成为可测变量）**
- d1 相对纯 dc 传输的 stretch（N2048）：q2 +41% → q4 +44% → **q8 +92.9%（峰）** → q16 +53.3%（回落）——语义代价非线性、**非单调**（q16 处 dc 自身恶化 +42% 快于 d1 的 +13%），不可从 isolated 排名外推，且与传输代价纠缠。
- Phase A 的 release 滞后（18-23us）+ per-slice release 曲线（t_release 间隔、release→gemm_start 延迟）构成机理级解释链。
- fc/dc 尺寸翻转（4KiB fcollect 赢 ↔ 1/64MiB put-signal 赢，Phase A）+ 16MiB 处 fcollect 崩溃（d0 比 ds 慢 40%+）：原语级排序也随消息尺寸翻转。

**C3 双基座能力向量 + 释放感知选择器**
- 统一抽象（第一篇的 shmem 多后端层）之上定义基座能力向量 B（transport、signal 通路、release 语义档位、干扰形态）。
- 选择器：(N, q, 基座) + B → 策略。配置轴第一版 = **B3 平衡带规则**（q≥8 ∧ 0.9≤ratio≤1.35 ∧ gap≤2% → C0，否则 C2）：**全 10 格 top1 10/10、worst regret 0.00%**（含 q16 第二正例）vs 带宽思维基线 8/10、5.49%。诚实口径：正例 2 格，规则=机先验+单点标定，嵌套 LOO 仍 7/10/worst 5.49%（已实测）；N4096/q16 判别实验（dsfix 批）检验"q 无独立效应"。
- 双基座各自选策略、不混 group（与 HetCCL 互操作、Unified OpenSHMEM API 统一划清界限）。

**C4 DUSHMEM/海光 DCU 首个系统公开测量**（文献空白 4；护城河 + 社区参考价值）

## 5. 选择器设计大纲（C3 的落地形态）

```
输入：负载特征 (N, q, 计算密度) + 基座能力向量 B + 离线图谱
离线阶段（一次性，每基座）：
  统一基准跑 10 路径 × 标定格 → 得到每格赢家 + 置信度
在线阶段（部署时）：
  1. 查表：精确命中格 → 直接返回（附置信度）
  2. 外推：未标定格 → 用 stretch 模型 + 重叠收益模型外推排序
     - stretch(q) ~ 协议轮询代价 × q（F3 曲线拟合）
     - overlap_gain(N,q) ~ min(comm, gemm)/max 形状（r1/d1 双族）
  3. 安全网：外推置信度低 → 回退保守基线（r0 / d0）
评估：leave-one-cell-out（挖一格用其余格训练外推，预测该格赢家）
```

## 6. Threats to validity（预答辩口径）

1. **4 卡 PCIe、无 NVLink/IB** → 主张限定"基座能力向量"框架而非绝对结论；NVIDIA 侧 4090 同为 PCIe，恰构成"同互联等级跨厂商"对照。
2. **单一负载族（AG-GEMM/sgemm）** → 这是 MoE/token 并行的核心原语（TokenWeave/COMET 同口径）；泛化留 future work，但反转现象在三族路径上均出现。
3. **噪声质疑** → T1 统计表：全格 Mann-Whitney p<1e-4 + 5/5 rep 方向一致（conservative 准则）；反转幅度 5.5% ≫ rep 间波动。
4. **DS 基线缺陷事故**（已修复+补测计划）：论文数据用 dsfix 根；修复过程本身可写进 measurement methodology（移植复核发现基准缺陷的案例）。
5. **Lagom 切割**：他们=资源参数轴的 isolated≠e2e 证据；我们=证明语义结构轴独立存在 + 代价可测 + 双基座选择器。related work 第一段明写。

## 7. 最小可发表单元（MPU）与降级路径

- **满配**：双基座 + 反转图谱 + 语义代价 + 选择器 LOO（投 OSDI/EuroSys/ATC 级）
- **中配**（NVIDIA 侧若 P2P 不可用导致 NVSHMEM 侧数据形态受限）：海光全矩阵 + NVIDIA 对照中说明互联差异本身就是 B 向量维度 → 选择器框架不变（投 SC/ICPP/ICPADS 级）
- **底仓**（一切实验受阻时）：双轴反转图谱 + 语义代价测量学 + 显著性（测量论文口径，投 workshop/短文也能立住）
- 关键：C1+C2 的海光侧证据链**已经闭合**，任何后续进展只做加法。
