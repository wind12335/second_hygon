## 一句话主张

在 GPU 集群的计算-通信重叠执行中，**基于带宽/孤立微基准的策略排序会发生系统性反转**；
我们证明这个反转不是噪声而是**服从双因子边界定律**（同步点数定位置、片计算量定斜率），
其病理根源是**流式协议的人工依赖（结构性串行化）**，并据此给出**释放感知的两级策略选择器**
（先协议族、后配置）。

## 统一分解雏形（把两侧模型并成一个框架，待拟合）

4090 侧交叉点模型 T_e2e = R_0↓ + Tail↑（q 轴），我方边界定律（d 族，q×N/q 平面），
可并为一个三段分解：

```
T(strategy) ≈ R_first(完成语义档位)  +  Σ_i max(comm_i, compute_i | 人工依赖调制)  +  Tail(同步点数)
```

- 各策略的差别 = 三项的**不同权衡**：d0/r0 买大 R_first 换零流水摩擦；d1/r1 买小 R_first
  付人工依赖代价；dc 用 credit 换取两者折中。
- 边界定律 = 该分解在 (q, N/q) 平面的等值线：q 项进 Tail、N/q 项进流水段。
- **已拟合（当晚完成）**：`统一分解拟合_20260902.md`——闭式 **P ≈ −44.3 + 9.22·q + (0.032−0.0154·q)·cols**
  （R²=0.907，符号预测 11/11 全对，幅度 LOO-RMSE 15pt）＝"位置项 q / 斜率项 cols 且斜率随 q 加深"
  的原文；控制量锚点 C(q)=3938+38.1·q（每片同步税直接可见）、FC=11566µs 常数；分块损失仅占惩罚
  0~6.5pt（流水线项 85–94%）→ 排除"小 GEMM 低效"替代解释。外推：q16 边界 N*≈7700，
  **N8192/q16 贴边界（预测 −6.6pt）= 立即可测的裁决格**（P16 预注册草案已写）。
