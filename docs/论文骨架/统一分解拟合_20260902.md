## 2. 惩罚分解：驳"小 GEMM 低效"替代解释

d1 的惩罚 P 里有多少只是分块 GEMM 损失？用每 N 的 min-q GEMM 作整块代理：

| 格子 | 实测P | 分块损失 | 流水线项 |

| N2048/q8 | +29.5 | +4.7 | **+24.8** |
| N4096/q8 | −21.0 | +5.6 | **−26.7** |
| N2048/q16 | +69.9 | +4.2 | **+65.6** |

| （q2/q4 全部 −24~−30） | | +0.0~+0.9 | 主体 |

**分块损失全程只有 +0~+6.5pt**，q8/q16 惩罚的 85–94% 是流水线项。
"q8 反模式只是小 GEMM 低效"这一审稿替代解释被控制量直接排除。

## 3. 边界定律闭式（M-A，LOO 最优）

四候选模型比较（LOO-RMSE）：M-C 纯线性 24.7pt ＜ M-B +1/cols 16.2pt ＜ **M-A +q·cols 交互 15.0pt** ＜ M-D 二次 67.5pt。

**P(N,q) ≈ −44.3 + 9.22·q + (0.032 − 0.0154·q)·cols**，cols = N/q（R²=0.907）

重参数化后每一项都是边界定律的原文：

- **位置项 +9.22·q**：每个同步点把整条曲线抬 9.2pt（"同步点数定位置"）✓
- **斜率项 (0.032−0.0154·q)/col**：q=2 时 ≈0（q2/q4 全列 d1 赢、与 cols 无关——实测全 −24~−30 ✓）；
  q=8 时 −0.091/col；q=16 时 −0.214/col——**cols 斜率随 q 加深**（"片计算量定斜率"，且越同步越灵）✓

**拟合质量（诚实口径）**：符号预测 **11/11 全对**；幅度 LOO-RMSE=15.0pt（P 跨度 −30~+70）。
残差大点：N512/q4（−11.2 vs −27.6）、N2048/q8（+6.1 vs +29.5）——64 列端幅度欠拟合，
**边界定律是符号/边界律，不是幅度律**；论文主张按此措辞。

## 4. 边界轨迹与立即可测的外推

P=0 等值线（模型扫描）：**q=8 → cols*≈323（N*≈2581）**（实测在 256(+29.5)~512(−21.0) 之间 ✓）；
**q=16 → cols*≈481（N*≈7700）**；q=32 → N*≈17401（**边界随同步点数右移**，超线性）。
