# 零基础概念讲解：名词与机理（2026-09-02）

> 目的：把 Phase B 全部名词从零讲清楚，不预设背景。组会/自查两用。

## 1. 实验在跑什么任务

4 张卡一起算大矩阵乘法 C = A×B。每张卡只持有 A 的 1/4，但算自己的结果需要完整的 A
→ 每张卡把自己那份发给其他三张（集合通信操作 **AllGather 全收集**）。
每张卡总时间 = **通信（收齐数据）+ 计算（GEMM）**。

两个旋钮构成实验平面：

| 旋钮 | 含义 | 取值 |
|---|---|---|
| **N** | 矩阵规模。越大 → 通信量与计算量都越大 | 512 / 2048 / 4096 |
| **q** | 切片数。数据切 q 片，第 1 片到了就开始算，同时传第 2 片……切得越细重叠机会越多，但每片多付"发/等通知"的协议开销 | 2 / 4 / 8 / 16 |

**"N2048/q8" = 一个实验条件（一个"格子"）**。主矩阵 = 10 个格子（q16 仅 N2048 补测）。

## 2. C0 / C2：通信库的两套配置

传输用 RCCL（NCCL 的海光版），可调：算法（Ring/Tree）、协议（Simple/Large）、
通道数（消息拆几路并行搬）。

- **C0 = 默认配置**（不调）
- **C2 = Ring + Simple + 8 通道**（调优出的）

孤立带宽测试（只通信无计算）C2 比 C0 快 1~3% → 工程惯例按此选 C2。

**引爆点**：N2048/q8 格子，孤立 C2 快 1.65%，端到端反而**慢 5.49%** —— "反转"。
（表内数字读法：+ = C2 快（正常）；− = C0 反超（反转）。）

## 3. Mann-Whitney U 检验：证明"不是运气"

每格子每配置独立跑 5 次（全新进程）。机器有抖动，需回答：
两组各 5 个时间的差别是真差别还是碰巧？

Mann-Whitney 是非参数检验（不要求数据正态；时间为偏态故不用 t 检验）：
把 10 个数混合随机分组，有多大概率分得像实际这么干净？概率 <0.05 → 显著（SIG）。

**"SIG + 5/5"** = 统计显著 ∧ 5 次重复方向全部一致（无一反水）。

## 4. 预注册与三次 MISS

**预注册**：跑实验之前把预测写进设计文档（带时间戳），跑完逐条对照。
防止"先看数据再编故事"；医学/心理学标准做法，系统领域少用（方法论卖点）。

| 编号 | 预测（跑前写死） | 实测 | 错误类型 |
|---|---|---|---|
| P2 | N4096/q8 反转 −9%~−3% | +1.8%，没反转 | 以为"N 越大反转越猛" |
| P3 | q16 加深 −8%~−12% | −5.4%，与 q8 同深 | 以为"q 越碎反转越狠" |
| P4 | stretch 继续涨 | 见顶回落 | 以为"开销随 q 无限涨" |

三次错法相同：**单调外推失败**。真相是效应只发生在窗口内：
**通信时间≈计算时间（双资源同时饱和）∧ q≥8 ∧ gap≤2%** —— 有界共振带
（类比药物的治疗窗口）。MISS 反而是卖点：不预注册很容易把论文写成
"反转随 q 加深"——那是错的。

## 5. stretch：语义的价钱

- d1 = 每片传完发信号、计算流收到就算的流式路径
- dc = 同样数据朴素搬运的纯传输基线（只传不算）

**stretch = (d1 − dc) / dc**：为"逐片通知、随到随算"这套语义比纯搬数据多付的百分比。

N2048 实测：41% → 44% → **93%（q8 峰）** → **53%（q16 回落）**。
回落原因：q16 连 dc 自己都恶化 42%，分母涨快过分子。
→ **语义代价非单调、与传输代价纠缠**（P4 的机理）。

## 6. 选择器（B3）：诊断后的药

只用孤立微基准可得的三个数：

| 传感器 | 定义 | 来源 |
|---|---|---|
| q | 切片数 | 负载参数 |
| ratio | t_comm / t_gemm | COMM_ONLY 与 GEMM_ONLY 各测一次 |
| gap | (t_comm(C0)−t_comm(C2))/t_comm(C0) | 两种配置各跑一次孤立带宽 |

规则：`q≥8 ∧ 0.9≤ratio≤1.35 ∧ gap≤2% → C0，否则 C2`。
人话：只有"切得碎 + 通信计算势均力敌 + 配置轴没油水"三条件齐踩，才反直觉选
"孤立更慢"的 C0；其余按带宽思维走没问题。

成绩（10 格）：**B3 10/10、worst regret 0.00%**；带宽思维基线 8/10、worst 5.49%。
指标：top-1（对几格）、worst regret（最惨亏多少）。

**诚实口径（LOO 留一验证）**：留一格、用其余 9 格学规则预测它 → 仅 7/10
（全矩阵只有 2 个正例，阈值漂移）。⇒ 规则 = 机理先验 + 三常数标定，
不是从数据学出的模型；真正的考验 = 换机器（NVIDIA 4090，预注册 P8–P13）。

## 7. 路径家族速查

**r 系列（RCCL 通信库）**：r0 整传整算｜rs 分片串行｜r1 分片重叠（事件）
**d 系列（DUSHMEM 对称内存）**：dc 只传不算（stretch 分母）｜fc fcollect 变体｜
d0 串行(fcollect)｜ds 串行(put+signal，d1 亲兄弟，formal 有 bug、dsfix 补)｜
**d1 重叠版（put+signal 逐片通知）**｜**d1w = d1 修复版（等待挪到独立流）**

**发现二（wait placement 病理）**：d1 的"等信号"在计算流上 → 计算流等时不能干活
→ 首个信号实际等到全部传输完才处理 → q2/q4 d1 比 d0 快 21~30%（正常），
**q8 反而慢 19~45%（三 N 全中）**。重叠写在协议里，没落在流分配上。
d1w 验证 = P6（dsfix 批）。
