## 0. 小节定位与主张边界

**本小节回答一个问题**：为什么"通信先完成"不等于"重叠收益到手"——即 release 语义如何把传输带宽优势转换（或吞掉）为端到端收益。五阶段链为骨架，每阶段只认直接证据。**重叠收益由 legal release、fragmentation、contention 共同决定**（对方【20】1 采纳）；本节隔离 release 路径（S3→S5），我方直接证据所在。

**主张（有直接证据；三条为 substrate-conditioned mechanism regularities，不称定律）**：
1. 本地完成 ≠ 可消费（S1→S3 有实测间隙，JM-H1）；
2. wait placement 决定 S3→S4 是否成立：等待放错流，重叠归零（JM-H2，三基座）；
3. S4→S5 有一条稳定的语义延迟梯子，路径族各占一档（JM-H3；A800 行待重提取）;
4. 逐片协议工作量为切片数的一阶载体、credit 深度是阈值变量而非旋钮（JM-H4/H5，双基座+双 rank 数）；
5. 两路径族的 rank 缩放方式分化（divergence），rank 数移动 d 族边界且方向随 workload 而异（JM-H6，BW1000）。

**不主张（当前无直接证据，显式标注 pending）**：
- S2 remote visible → S3 notification satisfied 中间段：双方 trace 证据都薄（见 §4）。不硬凑。

**不进本节**（Related Work 红线，双方【15】【16】共识）：EnergyLens/TileSight（white-box resolvable 一侧）、"首次发现不重叠可能更优"类主张；X-Stage 占 S1→S2（NVIDIA 侧主张）；Perseus 占 grouped signaling（作 H4 的可证伪假设来源，非本节竞争者）。

## 3. 机理叙事（三条 substrate-conditioned mechanism regularities 的合并表述——论文 §Mechanism 骨架；v3 按【20】4 因果动词纪律：trace 单独只写 shows/is consistent with，causes/explains 仅用于 API contract+干预实验+e2e 多源闭环场合）

**D1（释放语义 release semantics）**：重叠收益不由 S1→S2 的带宽单独决定，而由 legal release、fragmentation、contention **共同决定**；本节隔离 release 路径（S3→S5），它给出必要条件而非全部。三个锚点递进：本地完成≠可消费（H1，存在性）→ wait placement 一票否决（H2，三基座）→ 消费延迟有族级语义档位（H3，梯子；K500 derived，A800 待重提取）。
*反例边界（诚实记录）*：d1w 惰性 ±3% 说明"放对流"只是必要条件，事件桥开销在大 np 下开始可见（BW1000 +11%）。

**D2（协议税 protocol tax）**：分片化把一次集合通信换成 q 次逐片握手，产生 aggregate per-slice protocol work（K500 控制量：局部仿射 3938+38.1·q µs，**已测 q 域内边际项≈38.1µs/片**；A800 barrier 尾 rank 不对称 0.34–13.1ms——支持 stall 存在，不支持每片常数税）；credit 深度是阈值变量而非旋钮（H5，P24 w\*=4 operational threshold+kernel 覆盖 w1 归零/w8 回平台）。跨基座：格序守恒（结构可迁移）而税级平移 ×2.6（绝对标定基座相关）。**v3 删"必须在线感知"直推**：参数平移只支持"不能跨基座搬参数"，不支持"必须在线探"——单基座可本地离线标定甚至短路（K500 always-r1 9/9 即"机制复杂但当前域可短路"的正例，原样报告）；在线探针的完整论证（hidden residual 足以改变 ε-决策 + probe VOI 为正）在 selector 章闭环（P25 常驻进程+三基座四行表），本节引用不重复主张。
*可证伪出口*：grouped signaling 若把税摊薄 → 税主要来自 signal 次数；否则来自流切换/远端写。Perseus 占位，我方独立分支可测（【16】答 5）。**预注册将加逐片 signal 次数/字节计量插桩（对方【18】建议，已采纳）——无论摊薄与否都能归因到 signal 次数 vs 流切换 vs 远端写；A800 侧将在我们 admission 前给预期方向。**

**D3（rank 缩放分化 rank-scaling divergence，v3 改名）**：d0 成本∝np（一轮集合），d1 成本∝q·(np−1)（逐片推全部对端），但 d1 倍率 workload-dependent（512/q8 超线性 5.16×、2048/q8 1.40×、4096/q8 次线性 1.55×）——两条成本线随 rank 数**分化**，d 族边界 N*(q,np) 随 np 移动且**非单向**（小格右移、大格左移；H6 直接翻号证据：(4096,q8) np4 d1 慢 14.2% → np8 d1 快 16.1%），并把 A800 型"无过零"与 K500 型"域内过零"统一为同一成本几何的两种投影（H8 谱系，P21 下界）。
*开问题（v3 由预测降级）*：np≥3 水平或机制干预前，不预测边界随 np 的继续移动方向——留作下一轮预注册候选。
